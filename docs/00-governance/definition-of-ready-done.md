# Definition of Ready / Definition of Done

## Definition of Ready (story may enter a sprint)

- [ ] Business owner identified
- [ ] Workflow documented
- [ ] Field-level requirements available
- [ ] Validation rules agreed
- [ ] Dependencies identified
- [ ] Acceptance criteria written
- [ ] UI states and error states defined
- [ ] Security / permission impact assessed

## Definition of Done (story may be closed)

- [ ] Code reviewed and merged
- [ ] Unit + integration tests pass, coverage targets met
- [ ] Database migration tested up and down
- [ ] API contract documented in OpenAPI
- [ ] UI responsive and accessible
- [ ] Audit logging implemented for critical actions
- [ ] Security checks completed
- [ ] Performance baseline achieved
- [ ] QA passed
- [ ] UAT acceptance recorded
- [ ] Release notes + rollback steps prepared

## Phase Exit Gates

**Phase 0:** all DEC-001..DEC-012 signed off · BRD approved · RBAC matrix final · integration partner agreements in place · budget and timeline baselined.

**Phase 2-3:** HLD approved · ERD v1.0 approved · OpenAPI baseline published · ADRs raised for every structural decision.

**Pre-go-live:** see `docs/11-rollout/rollout-plan.md` go-live criteria.
